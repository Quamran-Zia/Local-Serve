LOCALSERVE - LOCAL SERVICE PROVIDER MARKETPLACE
================================================

ABOUT THE PROJECT
-----------------

Problem:
  Customers looking for electricians, plumbers, cleaners, tutors, or other
  professionals often depend on informal recommendations and have difficulty
  comparing available providers.

Solution:
  A marketplace website that allows customers to discover and request local
  services.


PAGES
-----
About (index.html)
  The first page that opens.
  It explains the problem and the solution,
  lists the main features and shows how the website works in three steps.

Book Service (book.html)
  Lets a customer browse providers by category (electricians, plumbers,
  cleaners and tutors). Each provider card shows availability, rate and
  rating. A booking form at the bottom is used to request a service.

My Requests (requests.html)
  Shows a summary of the customer's requests and a card for each one with
  the provider, date, time slot and status (Pending, Accepted or Completed).
